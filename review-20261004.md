### A-1 + C-1 — The guard audits every tool call in every project, into an un-ignored root file
- **Status:** verified · **Severity:** high · **Audience:** code (C-1: human-read)
- **Files:** `sdlc-lite-plugin/hooks/hooks.json:3-12`; `sdlc-lite-plugin/hooks/scripts/guard.py:69-74`;

  `dev-docs/architecture.md:150-151`; `README.md:256-258`; `sdlc-lite-plugin/hooks/tests/test_guard.py:77`
- **Claim:** The guard is a plugin-wide PreToolUse hook, so it runs on every tool call in every
  Claude Code session and project where the plugin is enabled. With no active run, it appends each
  call, including the full command text, to `if-runlog.jsonl` in that project's root. Only repos
  where `/sdlc-init` or Gate 0 ran ever get that file gitignored. architecture.md says the
  fallback is "gitignored at Gate 0", and the README says uninstalling makes "Everything …
  reversible". Neither is true in a repo where no run happened. The file has no size bound.
- **Evidence:** hooks.json `"matcher": "Read|Bash|Grep|Glob|Edit|Write|NotebookEdit|Task|Agent|Skill"`
  with no run condition. guard.py `runlog_path()`: `or (os.path.join(os.environ["CLAUDE_PROJECT_DIR"], "if-runlog.jsonl") if os.environ.get("CLAUDE_PROJECT_DIR") else None) or "/tmp/if-runlog.jsonl"`.
  guard.py:236 `with open(runlog_path(), "a") as f:` writes `"target": target` on every call;
  the comment at 233-234 says "The target is logged AT FULL LENGTH". `test_guard.py:77
  test_runlog_falls_back_to_project_dir_when_no_pointer` makes the fallback deliberate. The only
  `.gitignore` steps are SKILL.md Gate 0 step 4 and sdlc-init step 4. README.md does not mention
  `if-runlog`. architecture.md:150-151: "Before Gate 0 writes it / after Gate 11 removes it → falls
  back to `if-runlog.jsonl` at the repo root (gitignored at Gate 0)." This repo's root holds an
  `if-runlog.jsonl` (area C measured 91,546 bytes) of non-run calls such as
  `"target": "git ls-files", "guard_decision": "allow"`.
- **Fix:** Make the guard skip the audit write (and the run-scoped rules) when neither
  `.active-run` nor `$IF_RUNLOG` exists, or write outside the project dir. Drop the project-root
  fallback and its test. Then correct architecture.md §5 and the README uninstall answer.
