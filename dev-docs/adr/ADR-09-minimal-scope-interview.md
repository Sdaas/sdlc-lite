# ADR-9 — Grilling reaches clarity, not maximal scope

**Context**
- A thorough interview drifts toward completeness: a "minimal `parse_duration`" grew into a
  three-format parser in one dry run.

**Decision**
- Gate 1 first proposes a one-paragraph minimal version + an explicit out-of-scope list.
- The human confirms the boundary; grilling happens within it.
- Recommended answers default to the smaller option.

**Consequences**
- Each added mode is an explicit scope decision the human opts into.
